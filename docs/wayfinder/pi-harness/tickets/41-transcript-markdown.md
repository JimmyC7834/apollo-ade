# 41 — Markdown, artifact references, event chips

**Blocked by:** [37](37-shell-tokens-and-stack.md), [40](40-pinned-workbench.md) — a
reference has to have somewhere to open.
**Status:** ready-for-agent once both land.

## What to build

Both user and agent content render Markdown. The user message is a subtle card, no border,
rounded enough not to be a speech bubble, aligned slightly right with a left margin. The
agent message is **unboxed Markdown, no heading and no avatar**, with deliberate paragraph
spacing.

## References, and who is allowed to write them

Markdown links can target artifacts through a custom protocol:

```md
[src/App.tsx](artifact:app)
[browser preview](artifact:preview)
[working diff](artifact:diff)
[validation output](artifact:terminal)
```

Blue font colour only, no background chip. Clicking opens or activates the corresponding
Modal Workbench tab. `react-markdown` strips unknown protocols by default, so the custom
URL transform must be kept — the [Shell Guide](../../UIUX-UPDATE.md) warns about this
twice, which is usually a sign someone lost an afternoon to it.

**Decided: the harness emits these links, not the model.** A model instructed to write
`artifact:` URLs will get it wrong at some rate, and a broken artifact link is a dead click
with no error surface and no way for the model to learn it failed. Event chips already
carry structured tool results, so a reference can be built from data rather than from
prose. Nothing goes in the system prompt about this.

## Event chips

Tool calls and state changes render as compact pills between Markdown paragraphs. One chip
per event. Codicon, label, compact result, chevron. Clicking expands details **inline
beneath the chip** — details may include command output and an artifact action, and
expanding must not open another surface on its own.

This is the fourth appearance of the non-shifting rule: expanding a chip moves the content
below it, which is expected, but must not reflow the chip itself or the transcript's
horizontal metrics.

## Turn undo — shape only

The Shell Guide says *"activating Undo removes the corresponding change event from the
transcript."* **That sentence must not be implemented literally.** pi's session is
append-only JSONL; the Guide's own caveats admit it is a UI prototype, and this line
describes what the mock did rather than what the app can do.

[Ticket 28](28-session-undo.md) owns the behaviour and the dev has deferred it. This slice
builds the **affordance** only: visually secondary, adjacent to the affected event
sequence, present on completed turns. Wire it to nothing, or to a stub that says it is not
decided.

## The accessibility catch

*"No ADE heading or avatar before every response"* is right visually, and it removes the
only thing distinguishing speaker. Card surfaces and right alignment are invisible to a
screen reader. `transcript.ts`'s `asPlainText` and the `announce()` path carry that
distinction today, and `AccessibilityHelp.tsx` documents it.

**Visually absent, structurally present**: a visually-hidden speaker label per turn, and
the transcript stays a labelled list. Accessibility is on `context.md`'s never-trimmed
list, and honouring the Guide's rule in CSS rather than in the DOM costs nothing.

## Acceptance criteria

- [ ] User and agent content both render Markdown; the agent's is unboxed with no heading
      or avatar.
- [ ] `artifact:` links survive `react-markdown`, render blue with no chip, and open or
      activate the right Modal tab.
- [ ] Artifact references are generated by the harness from event data. Nothing instructs
      the model to write them.
- [ ] A reference to an artifact that does not exist fails visibly rather than silently.
- [ ] Event chips render one per event, expand inline, and opening one does not open
      another surface.
- [ ] A completed turn shows a secondary Undo affordance that does not yet undo, and says
      so.
- [ ] Each turn carries a visually-hidden speaker label; `asPlainText` still distinguishes
      speakers and `transcript.check.ts` still passes.
- [ ] `npm run check` and `npx tsc --noEmit` clean.
